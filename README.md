# Read N Slowly｜尼采慢慢讀

**閱讀《查拉圖斯特拉如是說》卷一與卷二**

國立陽明交通大學 115 學年度第 1 學期｜百川學士學位學程（Arête Honors Program）｜通識課程
永久課號 XDAP00026｜3 學分｜同步遠距｜授課教師：安勤之

以「經典慢讀」的方式，逐節細讀尼采《查拉圖斯特拉如是說》卷一與卷二。每週課前小組完成指定章節的閱讀並繳交討論筆記，課堂由同學導讀，教師回應與綜合討論。主線是：**從文本走回自己的生活世界。**

主要用書：尼采（2024）《查拉圖斯特拉如是說：給所有人與沒有人的一部書》，彤雅立譯，聯經。課堂另備德／英／中對照講義（孫周興、錢春綺、余鴻榮等譯本）。
